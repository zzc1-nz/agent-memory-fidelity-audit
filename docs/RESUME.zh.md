## 版本 A：研究 / 算法岗（推荐，最贴项目本意）

**Agent 记忆压缩忠实度审计基准**（个人项目，Python，2026）

> 针对 LLM Agent 长期记忆压缩「只报压缩率、不报忠实度」的问题，构建了一个测量
> 「压缩掉的到底是冗余还是任务所需事实」的基准，并证明应以**每正确答案 token 成本**
> 而非压缩率作为优化目标。

- **构建受控数据集**：30 段 20–30 轮 agent–用户长交互历史（编码/研究/日常三类任务），
  冗余占比实测 45.9%；注入 220 个关键事实，按**出现频次 / 显著性 / 嵌入深度 / 稳定性**
  四维标注，其中「被覆盖」维度复现分层抽象的记忆更新机制（保留旧值 → 自信的错误答案）。
- **实现并对比两种压缩范式**：LLM 分层摘要（map-reduce + 强制保留标识符）与确定性抽取式
  （TF-IDF + 标识符加权 + 冗余惩罚 + 时效性），均按预算压至约 25% 以保证同等压缩率下比较。
- **设计三类探测题**（高层概括 / 具体事实 / 多跳，共 300 题）与双上下文（全量 vs 压缩）
  评测矩阵；判定由与被测模型**不同的独立模型**执行，并在手工标注对上校准
  （14/14 一致，危险方向误接受 0/8）。
- **核心产出**：提出并计算「每正确答案 token 成本」及盈亏平衡条件
  （`准确率留存 > 压缩率`）。实测 30 段 / 300 题 / 166 万 token：
  基线 2,061 → 抽取式 **672**（-67.4%）、摘要式 1,877（-8.9%）。
- **关键发现**：① 两范式压缩率仅差 2.0% 而成本差 3.1 倍，说明压缩率没有区分力；
  ② LLM 摘要的收益被自身 26 万 token 生成成本吃掉，需每份记忆复用约 24 次才回本 ——
  这是工作负载属性而非压缩器属性；③ 84 个「由对变错」中 53 个所依赖事实**仍逐字保留**，
  属值混淆/检索失败，任何字面留存指标都会给满分。
- **工程**：132 项离线单测；数据集为 `(seed)` 纯函数可逐字节复现；全流程断点续跑；
  token 计量单点收口可归因。修复了一个 `fact_id` 跨会话冲突导致留存率恒为 100% 的静默 bug。

## 版本 B：工程 / 平台岗（弱化方法、强调交付与严谨性）

**Agent 记忆压缩忠实度审计基准**（个人项目，Python）

- 独立完成从数据集生成、两种压缩策略、评测框架、指标计算到报告与可视化的全链路，
  **132 项单元测试全绿**，无第三方评测依赖。
- 解决真实环境问题：目标网关为非 OpenAI 协议（SSE + 自定义鉴权），实现适配层接入，
  并在限流网关下实现**重试退避 + 磁盘缓存 + 断点续跑**，900 次模型调用 0 失败。
- **成本可控性**：所有 LLM 调用经单一客户端收口，统一 `cl100k_base` 计量，
  成本可精确归因到（角色/会话/策略/题）四元组，最终 166 万 token 全部可对账。
- **数据可信**：评测结论用 pass 数据反查 —— 指标 JSON、失败明细、图表与报告从同一批
  原始答案生成，且原始判定输出全部保留可复查。
- 主动做了两件「让结论站得住」的事：判定器用不同模型并在人工标注上校准（避免自我偏袒）；
  对已发布指标做一致性审计，发现并修复了会让留存率虚高的聚合 bug。

## 面试可能被追问的点（提前准备好）

**「为什么 30 段就够？」**
不是统计显著性意义上的够，而是**控制变量**意义上的够：我要的是每个属性格子（如
深埋×背景）有足够的事实进入分母。实测每格 n=30~134，足以看出量级差异（4 倍）。扩到
100 段是线性加成本，结论方向不会变 —— 这点我在报告里写明了边界。

**「LLM judge 靠谱吗？」**
不完全可靠，所以我做了三件事：判定器与作答器不同模型；在 14 对手工标注上校准
（含「合理但错误」「过时值」「拒答」三类陷阱，全部判对）；原始判定全部落盘可复查。
我不声称判定器是准的，我声称它**可审计**。

**「为什么摘要式这么吃亏？是不是你把它写差了？」**
我专门做了反向防护：摘要臂有「欠填充」检测（低于预算 75% 会要求模型补充），
避免它靠「携带更少上下文」来虚高准确率；预算不足时按具体值加权丢弃整条 bullet，
避免系统性砍掉会话尾部（被覆盖事实的当前值在那里）。它吃亏的真实原因是**生成成本**，
这恰恰是我想暴露的东西。

**「那结论到底是什么？」**
压缩划算的充要条件是 `准确率留存 > 压缩率`。所以问题不是「用不用压缩」，而是
**「你的工作负载会不会复用同一份记忆」** —— 复用少，选抽取式；复用多（长期记忆、
多轮检索），抽象才可能回本。
